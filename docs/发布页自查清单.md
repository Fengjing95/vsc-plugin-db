## 三、Open VSX 渠道（一次性配置 + 上线后核对）

配置指引同步写在 release.yml「发布到 Open VSX」步骤注释里；未配置前该步骤在流水线中 notice 跳过，属预期。

| # | 事项 | 操作 |
|---|---|---|
| O-1 | ☐ **注册/登录 open-vsx.org** | 用 GitHub 账号登录 https://open-vsx.org |
| O-2 | ☐ **认领 publisher 命名空间 `db-explorer-dev`** | `npx ovsx create-namespace db-explorer-dev -p <token>`（须与 package.json `publisher` 一致）。注意：因 VSCode Marketplace 已存在同名扩展，Open VSX 要求该命名空间的 **owner 权限**；未走所有权认领前页面带 Unverified 标注（不影响安装），可后续按 open-vsx.org 的 namespace ownership 流程提交认领 |
| O-3 | ☐ **生成 Access Token 并配置仓库 Secret** | open-vsx.org 头像 → Settings → Access Tokens → Generate New Token（**关闭弹窗后不再显示，立即复制**）→ GitHub 仓库 Settings → Secrets and variables → Actions → New repository secret，名称 `OVSX_PAT` |
| O-4 | ☐ **上线后页面核对** | 下一次 tag 发版后：https://open-vsx.org/extension/db-explorer-dev/db-kit 页面元素继承 VSIX 内 README（与 Marketplace 详情页同源）；核对版本号、README 渲染、图标正常；安装验证 `ext install db-explorer-dev.db-kit`（VSCodium / Open VSX 兼容端） |
