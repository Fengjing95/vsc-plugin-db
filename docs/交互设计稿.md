## 1. 信息架构与导航

```
活动栏
└── 🛢 数据库（viewContainer: dbExplorer.container）
    ├── 数据库连接树（TreeView，主视图）
    ├── 查询历史（TreeView，P1，历史/收藏两个节点组）
    └── 视图标题栏按钮：[＋新建连接] [⟳ 刷新] [⇕ 全部折叠]

编辑器区
├── 表格视图     → Webview Tab，标题 "表名 @ 库 (连接名)"，图标按驱动
├── SQL Console → 原生 untitled sql 文档 Tab
└── 结果面板     → Webview Panel（用户可拖拽到任意编辑组，如编辑器下方）
```

- 单击表节点 = 打开表格视图（US-01：树聚焦 → 单击，2 次操作）
- 同一表重复打开复用已有 Tab（按 `connId/db/table` 去重），不无限开新 Tab
- 编辑器 Tab 上有未提交变更时显示圆点标记（同未保存文件的脏标记语义）

## 3. 连接表单

### 3.1 线框

```
┌─ 新建连接 ────────────────────────────────────┐
│ 类型  [ MySQL ▾ ]            标识色 ●●●●●●    │
│ ┌─ 基础 ────────────────────────────────────┐ │
│ │ 名称*   [本地 MySQL            ]           │ │
│ │ 主机*   [127.0.0.1]  端口* [3306]          │ │
│ │ 用户*   [root      ]  密码  [●●●●●●●●]     │ │
│ │ 默认库  [myapp     ]                       │ │
│ └───────────────────────────────────────────┘ │
│ ▸ 环境（env: dev/test/prod · 分组 · 颜色）      │
│ ▸ 安全（只读开关 · SSL）                        │
│ ▸ 高级（SSH 隧道 · 超时 · 连接参数）             │
│                                               │
│  状态行：ⓘ 尚未测试                             │
│        [🔌 测试连接]        [取消]  [保存]      │
└───────────────────────────────────────────────┘
```

### 3.2 规则

| 项 | 规格 |
|---|---|
| 字段渲染 | 完全由驱动 `FormSchema` 驱动；无 schema 的分组整体隐藏 |
| 校验时机 | 失焦即时校验；`保存`/`测试` 前全量校验；错误字段红框 + 下方一行错误文案 |
| 校验规则 | required 为空、number 越界、validator（port 1-65535 / host / regex） |
| 测试连接状态机 | `idle → testing(按钮转圈，其余禁用) → ok(状态行绿色 ✓ "连接成功 · 12ms · MySQL 8.0.36"，2s 后淡出) / fail(状态行红色 ✗ + 错误码文案 + "查看详情"链接)` |
| 测试与保存独立 | 测试成功不自动保存；保存不强制先测试，但未测试过时保存按钮旁提示“尚未测试连接” |
| 密码字段 | 永不回显（编辑时显示占位 `●●●●●●`，留空 = 沿用原密码）；不写入任何本地明文 |
| 编辑模式 | 标题变“编辑连接”；删除连接需确认 Modal（§6 简化版，不用输名称） |
| 未保存离开 | 表单有改动时关闭 → 确认“放弃未保存的修改？” |
| 驱动切换 | 切换驱动类型即重渲染字段，已有值按 key 保留，其余丢弃并提示 |

## 4. 表格视图

### 4.1 视图状态机（顶层）

```
loading ──数据到达──▶ ready ◀──刷新/翻页──┐
                      │  ▲               │
                      编辑│  │再编辑        │
                      ▼  │               │
                    dirty ──提交──▶ preview ──确认──▶ committing
                      │  ▲            │ 取消           │
                      │  └──(重试)────┼────────────────┤
                      撤销全部          ▼               ├─成功─▶ ready（Toast + 刷新当前页）
                    (回 ready)        (关闭弹层)        └─失败─▶ error
                                                        （ChangeSet 保留，错误行高亮，
                                                          行内"重试/放弃"操作）
```

- `dirty` 态：工具栏 `[提交变更 (N)]` 高亮 + 轻微脉冲动画；Tab 标题显示 `表名 ●`
- `error` 态：错误行左侧红条 + 行首 ⚠ 图标；悬停显示错误文案（错误码 → 文案映射见 §9.2）；行级操作 `重试 | 放弃该行`
- 关闭视图且 `dirty` → 确认弹窗“有 N 条未提交变更，放弃并关闭？”

### 4.2 单元格视觉规范

| 内容 | 展示 |
|---|---|
| NULL | 灰色斜体 `NULL`（不可与空串混淆） |
| 空串 | 灰色中点 `·` |
| 二进制 | 🔒 图标 + `<binary, N bytes>`，点击打开查看器 |
| JSON | 截断原文，点击打开 JSON 查看器（折叠树 + 编辑态） |
| 超长文本 | 截断 + 右上角 ▤ 角标，点击打开大文本编辑器 |
| 日期时间 | 按 4.4 契约展示，悬停 tooltip 显示“按连接时区解释” |
| 已修改 | 黄底 + 右上角黄三角；悬停 tooltip 显示 `旧值 → 新值` |
| 已删除行 | 整行红色删除线 + 行首 ↺（撤销删除） |
| 新增行 | 行首绿色 ＋，整行浅绿底 |
| 冲突/错误行 | 左侧红条 + ⚠ |

### 4.3 键盘与鼠标

| 操作 | 行为 |
|---|---|
| 双击 / Enter / F2 | 进入单元格编辑 |
| 编辑中 Enter | 确认并下移一行；Tab 确认并右移；Esc 取消 |
| 编辑中 ↑↓ | 确认并移动（文本多行编辑器除外） |
| Ctrl+C | 复制选中区（TSV，粘贴到 Excel 可用） |
| Delete / 右键 | 标记删除选中行（进入 ChangeSet，不落库） |
| 列头点击 | 排序（服务端下推，↻ 重取当前页）；再点反向，三点取消 |
| 列头拖拽 | 调列宽；右键列头：隐藏/冻结/复制列名 |

### 4.4 筛选构造器

```
🔍 筛选: [ status ▾ ][ = ▾ ][ "active" ✕ ]  [ + 条件 ]   [▶ 应用] [↺ 清空]
```

- 行式构造：列（下拉，含类型图标）· 操作符（按列类型过滤：文本 → like/eq/…，数值 → gt/…，全部 → isNull/…）· 值（类型化输入：日期选择器/布尔下拉/多值 in）
- 未点“应用”的改动以蓝点提示；应用即服务端下推并回到第 1 页
- 值含特殊字符自动转义展示；`in` 支持粘贴多行

### 4.5 NULL / 空串切换

- 单元格右键菜单：`设为 NULL`（当前为空串/值时）、`设为空串`（当前为 NULL 时）、`复制值`、`复制为 WHERE`
- 设为 NULL 即进入 ChangeSet（可撤销）

### 4.6 查看器弹层（大文本 / JSON / 二进制）

| 查看器 | 结构 |
|---|---|
| 大文本 | 全屏编辑器（等宽字体）＋[格式化]；保存写回 ChangeSet；`lazyCell` 未加载前显示“加载中” |
| JSON | 左：折叠树预览；右/切换：原文编辑态；格式合法校验，非法时保存按钮禁用并提示 |
| 二进制 | 只读：hex 视图（前 64KB）＋ 图片预嗅探（PNG/JPEG/GIF 头直接预览）＋ [另存为文件] |

### 4.7 分页栏细则（评审补充）

- `totalCount` 已知：`第 1-50 行 / 共 12,345 行` + 页码跳转
- `totalCount` 缺省（不做全表 COUNT）：显示 `第 1-50 行`；元数据行估算（`rowEstimate`）可得时附 `约 12.3k 行`（“约”字必须带，与精确值区分）；隐藏页码区，仅「上一页/下一页」，翻到空页提示“已是末页”
- 每页行数选择：50 / 100 / 200 / 500

## 5. 变更预览 Modal

```
┌─ 提交变更（3）─ myapp.users ─────────────────────┐
│ ██ 目标环境：测试 (test) · 连接：本地 MySQL        │  ← 环境色条（prod 为红条）
│                                                  │
│ 2 条 UPDATE · 1 条 INSERT · 0 条 DELETE           │
│                                                  │
│ ┌ ▸ UPDATE users SET name=?, email=?            │ │
│ │     WHERE id=1 AND name=? AND email=?          │ │  ← 参数化语句，可展开
│ │     参数: ["张三改","z@x.com","张三","z@x.com"]  │ │
│ ┌ ▸ INSERT INTO users (name, email) VALUES (?,?) │ │
│ └ ▸ …                                            │ │
│                                                  │
│ ☑ 全部语句在单事务内执行，失败自动回滚               │
│                                                  │
│              [折叠全部 ▾]   [取消]  [确认提交]      │
└──────────────────────────────────────────────────┘
```

- prod 环境：确认按钮初始禁用，需在环境条旁输入框输入**表名**（匹配后启用），同时无“折叠全部”快捷——预览强制逐条可见（概要设计 5.8）
- 语句按行分组：UPDATE 显示 `旧值 → 新值` 摘要行；点击展开看完整 SQL 与参数
- 变更超过 50 条时列表默认折叠（仅显示统计行 + 首组），展开后虚拟滚动，1000+ 条不卡顿
- ESC = 取消；确认后 Modal 关闭，表格进入 `committing`（工具栏按钮转圈，禁止编辑）

## 6. 危险操作确认 Modal

用于：删表、清空表、删索引、Console 危险语句（§7.3）。

```
┌─ ⚠ 删除表 ────────────────────────────────┐
│ ███ 生产环境 (prod) · 连接：线上主库         │   ← prod 红条，dev/test 灰/蓝条
│                                            │
│ 即将从 myapp 删除表 users 及其全部数据。      │
│ 此操作不可撤销。                             │
│                                            │
│ 请输入表名以确认：[            ]             │
│                                            │
│                     [取消]  [删除]          │
└────────────────────────────────────────────┘
```

- 输入与目标名**完全匹配**（trim 后）才启用确认按钮；粘贴含空格自动 trim
- prod 恒触发；dev/test 由 `dbExplorer.safety.confirmOnNonProd` 控制
- `E_READONLY` 连接上不弹出该 Modal——入口已在树菜单隐藏，且 Host 层兜底拒绝

## 7. SQL Console

### 7.1 编辑器绑定

- 新建 Console = untitled `sql` 文档 + Host 内存绑定 `{ connId, db }`
- 状态栏（编辑器右下）常驻：`🛢 本地 MySQL · myapp ▾`，点击切换连接/库（列出该连接的库）
- 未绑定连接时执行 → 提示“请先选择连接”并聚焦状态栏选择器
- 另存为 `.sql` 文件后，绑定持久化到 `workspaceState`，重新打开文件自动恢复

### 7.2 执行

- `Ctrl+Enter`：有多行选区 → 执行选区；否则执行光标所在语句（`node-sql-parser` 切分定位）
- 执行中：状态栏转圈 + 可点击取消（转为 AbortSignal，`E_CANCELED` 静默提示“已取消”）
- 结果面板未打开时自动在当前编辑组右侧打开；已打开则复用（D-02）

### 7.3 结果面板

```
┌ 结果面板 ────────────────────────────────────────┐
│ [结果 1 (50 行)] [结果 2] [消息]        [⇩导出] [⨯] │
│ ┌──────────────────────────────────────────────┐ │
│ │  （只读表格，复用表格视图组件，同 §4.2 视觉）     │ │
│ └──────────────────────────────────────────────┘ │
│ SELECT * FROM users LIMIT 50 · 12ms · 50 行       │  ← 状态行
└───────────────────────────────────────────────────┘
```

- 多语句 → 按语句生成结果 Tab；非 SELECT 语句的 Tab 名为“消息”，内容：`3 rows affected · 8ms`
- `messages`（警告）入消息 Tab；`truncated` 时状态行追加黄字“结果已截断至 1000 行”
- 消息 Tab 恒显示最后一条语句的耗时/影响行数/错误摘要

### 7.4 危险语句横幅（DangerGuard 联动）

执行前判定为危险（无 WHERE 的 UPDATE/DELETE、DROP、TRUNCATE）→ 面板顶部内联横幅：

```
⚠ 检测到可能影响全表的语句（UPDATE 无 WHERE）。     [仍要执行]  [取消]
```

- prod 环境：横幅升级为 Modal（输入表名确认，§6）
- 拦截不落历史；`仍要执行` 记录一次“用户确认覆盖”事件（仅本地日志）

## 9. 通知与错误呈现

### 9.1 三级呈现

| 级别 | 形式 | 何时 |
|---|---|---|
| 轻提示 | Toast（3s 自动消失，右下角） | 成功类：提交成功/导出完成/复制成功 |
| 需知晓 | Toast 常驻 + 动作按钮 | 失败但可重试：导出取消、重连失败 |
| 需处理 | Modal 或行内错误 | 危险确认、提交冲突 |

### 9.2 错误码 → 文案基准（UI 侧映射，驱动只给 code）

| code | 文案模板 | 附带动作 |
|---|---|---|
| E_AUTH | 认证失败：请检查用户名/密码 | [编辑连接] |
| E_CONN | 无法连接到 host:port（网络不可达或拒绝） | [重试] [查看详情] |
| E_TIMEOUT | 操作超时（15s），可在设置中调整 | [重试] |
| E_READONLY | 连接已开启只读保护，写操作被拒绝 | [查看连接设置] |
| E_CONFLICT | 数据已被他人修改，请刷新后重试 | [刷新并放弃] [保留我的修改] |
| E_CONSTRAINT | 违反约束：{detail}（唯一键/外键/非空） | [定位错误行] |
| E_PERMISSION | 当前用户权限不足 | [查看详情] |
| E_NOT_FOUND | {对象} 不存在，可能已被删除 | [刷新] |
| 其他 | 操作失败：{message} | [查看详情] |

`查看详情` = 打开输出面板 `Database Explorer` 通道（含 detail 与时间戳，已脱敏）。

> “保留我的修改”语义：重取该行当前值 → 校验变更列是否已被他人修改 → 未被修改则基于新基线重新预览提交；已被修改则逐列提示选择保留方。**不静默覆写**。

## 11. i18n 与无障碍

**i18n**
- 全部文案走 `vscode.l10n`，key 命名 `<域>.<对象>.<动作>`：`tree.menu.copyName`、`table.commit.confirmTitle`、`error.E_CONN`
- 本文中的中文文案即中文资源包初稿；英文包 M2 起同步维护
